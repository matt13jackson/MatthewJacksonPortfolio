# Matthew Jackson GitHub Portfolio

GitHub Pages-ready HTML/CSS/JavaScript portfolio.

## Before publishing
Open `index.html` and replace `YOUR-EMAIL-HERE` with the email address you want to publish.

## GitHub Pages
1. Create a GitHub repository such as `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
